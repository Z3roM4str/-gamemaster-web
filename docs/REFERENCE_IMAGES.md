The original binary reference images were supplied in ChatGPT but are not stored as binary files in this repository. This document preserves what matters about them for Codex/art direction.

## Current web composition reference

### STYLITES — MEK Gallery

Reference URL:

- https://www.mek.gallery/releases/stylites

Use STYLITES as a reference for **page-scale composition**, not as a template to clone.

What is useful for GameMaster:

- the page behaves like one continuous graphic composition rather than a stack of conventional cards;
- large high-saturation chromatic fields are used as real compositional masses;
- the composition is confident enough to let color architecture dominate the viewport;
- content and art feel structurally integrated rather than separated into “UI” and “decoration”.

What GameMaster should change relative to this reference:

- substantially more black/near-black negative space;
- less continuous blue coverage to reduce saturation/fatigue;
- strategically more red as an independent foreground/focal plane;
- retain the commercial catalog behavior of Game Pass/Netflix-style browsing;
- preserve recognizable original game cover art inside the composition;
- never copy STYLITES artwork, exact layout, transitions, typography or page structure.

The current synthesis is documented in `docs/DESIGN_DIRECTION_STYLITES.md`.

## Shared visual DNA

The strongest common features across these references are:

- three-color discipline: red / blue / black
- hard edges rather than soft neon glow
- posterization and engraving/halftone texture
- figurative content paired with mathematical/technical motifs
- repeated geometric glyphs
- strong black negative space
- plane hierarchy rather than generic chromatic aberration
- red often functions as a front or focal plane, blue as a rear structural plane
- materially different red and blue geometries rather than offset copies

## Current area hierarchy

For the next visual iteration, use this as a composition target rather than a strict quota:

- 55–65% black / near-black
- 20–30% blue
- 10–15% red
- <5% off-white / neutral gray

The site should read primarily as black. Blue is the rear structural field. Red is a sparse but strong focal/front field.

## How to adapt the references to the site

Do not turn every game cover into engraving/halftone or force it into red/blue.

Original/authorized game cover art should normally remain recognizable and color-accurate. Apply the chromostereoscopic language primarily to:

- page-scale background architecture;
- hero composition;
- section transitions;
- editorial feature banners;
- category identity art;
- selected/focus markers;
- procedural placeholders for missing artwork;
- loading/empty states;
- technical/topographic/network structures surrounding the catalog.

This allows the covers to function as normal recognition objects while GameMaster’s red/blue/black system creates the spatial environment around them.

Once owner-supplied brand/logo/cover assets are added to the repository, preserve their identity and integrate them into this system instead of repainting them blindly.
